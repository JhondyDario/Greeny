# ---------------------------------------------------------------------------
# Condicion:   when = <direccion> <tipo> <operador> <valor>
#
#   direccion  main+0xOFFSET  o  heap+0xOFFSET
#              punteros: main+0x1A2B3C->0x10->0x48
#              (lee un puntero en main+0x1A2B3C, le suma 0x10, lee otro
#               puntero ahi, le suma 0x48, y ESE es el dato)
#   tipo       u8 u16 u32 u64   s8 s16 s32 s64   f32 f64
#   operador   == != > >= < <=
#              &   todos esos bits encendidos     !&  todos apagados
#   valor      decimal o 0xHEX (decimales con punto para f32/f64)
#
# Varios when = se tienen que cumplir TODOS a la vez.
# points = puntos que da el logro (por defecto 10).
# name.en / desc.en = traduccion al ingles (opcional).
# hold = milisegundos seguidos que debe cumplirse (por defecto 500).
# ---------------------------------------------------------------------------
